# Fotos de fondo

Fotos de estadios reales tomadas de [Unsplash](https://unsplash.com) (licencia Unsplash: uso libre,
también comercial, sin necesidad de permiso; no se usaron fotos "Unsplash+"). Se recortaron y
comprimieron a WebP para que la página cargue rápido.

| Archivo | Escena | Dónde se usa |
|---|---|---|
| `noche-arco.webp` | Estadio con techo en arco, de noche | Inicio (modo oscuro) y páginas sin foto propia |
| `noche-tribuna-llena.webp` | Tribuna llena, de noche | Partidos, Comparación/Evolución y la tarjeta "Próximo partido" |
| `noche-niebla.webp` | Reflectores entre la niebla | Análisis y Reportes (modo oscuro) |
| `noche-techo-rojo.webp` | Techo con luces rojas | Jugadores (modo oscuro) |
| `atardecer.webp` | Atardecer naranja | Mi equipo (modo oscuro) |
| `aerea.webp` | Vista aérea de un estadio | Diseño táctico |
| `sillas-azules.webp` | Filas de sillas azules | Estructuras de datos |
| `dia-tribuna-llena.webp` | Tribuna llena, de día | Inicio y Reportes (modo claro) |
| `dia-cubierta.webp` | Estadio cubierto, de día | Partidos y Mi equipo (modo claro) |
| `dia-nublado.webp` | Estadio vacío, día nublado | Análisis y Comparación (modo claro) |
| `dia-gradas-azules.webp` | Gradas azules, de día | Jugadores (modo claro) |
